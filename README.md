# Sistema de Chamados com Python

Sistema web simples para abertura, acompanhamento e atualização de chamados de suporte técnico.

## Objetivo

Demonstrar conhecimentos em Python, Flask, banco de dados SQLite, CRUD, organização de código e lógica de atendimento técnico.

## Funcionalidades

- Cadastro de chamados
- Listagem de chamados
- Atualização de status
- Classificação por prioridade
- Registro de solicitante, categoria e descrição
- Dashboard simples com total de chamados por status

## Tecnologias utilizadas

- Python 3
- Flask
- SQLite
- HTML/CSS
- Bootstrap

## Como executar

```bash
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python app.py
```

Depois acesse:

```text
http://127.0.0.1:5000
```

## Diferencial para recrutadores

Este projeto simula uma rotina real de Service Desk/ITSM, aproximando o conhecimento técnico da experiência prática em suporte corporativo.
